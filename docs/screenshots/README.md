# Capturing genuine screenshots

Only add screenshots captured from this application running locally or from a verified deployment. Do not use mockups or generated images as proof that the site runs.

1. From the project root, run `npm install && npm run dev`.
2. Open the Vite URL and inspect both a desktop viewport (for example 1440 × 1000) and a mobile viewport (for example 390 × 844).
3. Capture with your browser's built-in screenshot/full-page capture or a configured browser automation command.
4. Save authentic captures here, such as `portfolio-desktop.png` and `portfolio-mobile.png`.
5. Update the Screenshots section in the root README with the actual images and capture date. Ensure private browser data is not visible.
