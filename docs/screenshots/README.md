# Capturing genuine screenshots

Screenshots belong here only after they are captured from this application running locally or from a verified deployment. Do not use mockups or generated images as proof that the app runs.

1. Install dependencies and start the site with `npm install && npm run dev` from the repository root.
2. Open the Vite URL in a browser and inspect the page at desktop width (for example 1440 × 1000) and mobile width (for example 390 × 844).
3. Capture the page using your browser's built-in screenshot/full-page capture or an explicitly configured Playwright screenshot command.
4. Save genuine captures in this directory, such as `portfolio-desktop.png` and `portfolio-mobile.png`.
5. Update the Screenshots section in the root README with the images and capture date. Check that no private browser data is visible.
