# Hichem Bouhamed — Developer Portfolio

A responsive personal portfolio for presenting Hichem Bouhamed's software engineering interests, technical skills, selected projects, education, and ways to get in touch. Personal details beyond the name and student/developer context will only be included when verified.

## Planned features

- Accessible, responsive dark-theme interface with clear navigation.
- Professional introduction, about, skills, programming languages, and education sections.
- Featured projects linking to their source repositories.
- Training and certifications section that can be populated with verified details.
- Contact section with no invented personal details.
- Reduced-motion support and documented local development workflow.

## Technology stack

- React and TypeScript
- Vite
- Modern CSS
- Lucide React icons

## Project status

This repository is being initialized. Implementation and test status will be documented as features are added; no deployment is implied.
